# BUY-IONIC TRIVIA

A web-based, visually engaging trivia game for team play at work, inspired by classic arcade and sci-fi aesthetics.

## Features
- Multiple choice trivia questions
- 10-second timer per question
- Player name entry and lobby system
- 5-15 players can join via a link (before game starts)
- Animated, interactive space-themed background (UFOs, explosions, stars, galaxies, nebulae)
- Scores tracked and displayed for all players at the end
- Space Invaders-style laser cannon (keyboard controlled)
- Star Wars-style animated title

## How to Play
1. **Open the app in your browser.**
2. **Enter your name** in the lobby screen.
3. **Wait for all players to join.** Share the link with your team (5-15 players recommended). Only those in the lobby before the game starts can play.
4. **Start the game.**
5. **Answer each trivia question** by clicking your choice. You have 10 seconds per question.
6. **Watch your score!** Points are awarded for correct answers. Compete with your coworkers for the top spot.
7. **Enjoy the animated background:**
   - Use the left/right arrow keys to move the laser cannon at the bottom.
   - Press the up arrow or spacebar to fire lasers at falling UFOs for fun (does not affect trivia score).
   - Watch for explosions, twinkling stars, galaxies, and nebulae.
8. **See the final scores** at the end of the game.

## Tech Stack
- Next.js (React, TypeScript)
- Tailwind CSS

## Local Development
1. Clone the repo:
   ```bash
   git clone <repo-url>
   cd triviaApp
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the app:
   ```bash
   npm run dev
   ```
4. Open your browser to [http://localhost:3000](http://localhost:3000)
